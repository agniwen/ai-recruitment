# 真人面试在同一工作区的不同用工单位间保留约面优先期

某用工单位成功新建真人面试轮次后，同一工作区的其他用工单位暂时不能为同一候选人约面。同一用工单位内部不受此规则限制，工作区之间不共享锁定。

平台管理的「面试参数」配置锁定时长，默认为 48 小时。每个新建轮次保存当时的时长快照，历史轮次采用 48 小时；修改平台参数不会改变已有轮次。锁定从真人面试轮次的创建时间开始，截止时间为 `createdAt + lockHours`，不使用预约开始时间、有效期或后续会议创建时间。调整排期不会延长或缩短该轮次的锁定。

一句话规则：同一候选人在其他用工单位存在尚未完成点评、未取消且创建时间仍在锁定时长内的真人面试轮次时，不允许约面。

面试点评提交后，轮次状态变为 `completed`，该轮次立即解除限制；取消轮次或从创建起经过快照时长也会解除限制。单独结束视频会议、预约时间过去或面试有效期过期不会提前解除限制。存在多个轮次时，只要仍有一个轮次符合锁定条件，就继续限制其他用工单位。此规则不改变候选人结论和 Offer 规则。

在点击安排真人面试及安排真人复面入口时检查并提示，不打开被拦截的排期表单；保存轮次、创建会议和调整时间时再次检查。同工作区的排期写入通过事务锁串行校验，防止同时保存绕过限制。提示文案固定，不提供后台文案配置。

同一候选人按相同简历池来源、简历内容哈希、规范化邮箱或去除格式符号后的电话识别，不按姓名匹配。无可用身份标识的独立记录不自动合并。提示仅返回锁定用工单位名称、解除时间和等待信息。
