# 平台安全改造：IP 加密与后台两步验证

日期：2026-10-16。范围以本版本为准，替代此前涉及所有环境信息和音视频加密的扩大方案。

## 本期业务范围

继续使用现有平台后台，无需新建另一套管理系统。本期只处理 IP 加密存储、平台管理员两步验证，以及点击查看单条 IP 的流程。

| 内容 | 本期行为 |
| --- | --- |
| 面试诊断日志中的 IP | 入库前加密，列表仅返回是否存在 IP |
| 入场凭据验证记录中的 IP | 入库前加密，点击查看时单独解密 |
| 媒体环境快照中的 IP | 保留加密副本，原日志清理后仍可按权限查看 |
| 登录会话中的 IP | 单独加密保存，原 IP 字段置空，不在登录接口返回 |
| 普通业务信息、指纹、浏览器标识、User-Agent | 延续现有业务行为 |
| 视频、音频、截图文件和现有链接 | 本期不实施文件或链接加密 |
| 新管理系统、网络白名单、全站密码规则调整 | 本期不新增 |

媒体快照的 IP 属于本期字段范围，媒体文件本身不属于本期加密范围。未来如需保护媒体链接，应另行设计鉴权、有效期和撤销机制；仅编码或加密 URL 不能代替权限检查。

## 管理员操作流程

1. 使用现有飞书、Google 或密码登录。
2. 点击进入平台后台。尚无有效授权时自动跳转 `/platform/verify`，保留原页面和查询条件。尚未绑定验证器时直接显示二维码，扫描并输入六位验证码，无需退出重新登录。
3. 首次验证成功后，保存十个一次性恢复码，勾选保存并点击“继续”，等待后台权限与页面数据刷新后自动进入。二维码和恢复码只在绑定过程中显示，不发送到第三方二维码服务。
4. 已绑定管理员输入当前验证码，通过后返回原页面；后台授权按最后操作时间维持十五分钟，持续操作时无感续期。
5. 列表显示“查看 IP”，不自动解密。点击后，服务器再次核验账户、平台管理员角色、当前会话、验证凭证及记录范围，返回本条 IP。
6. 闲置十五分钟、按钮检测到过期或接口返回需要验证时，立即隐藏后台内容并跳转统一验证页，不停留显示红色提示。验证后返回原页面；修改和解密操作不自动重放，查看 IP 需再次点击。
7. 明文显示一分钟后或授权到期时自动隐藏；切走标签页、离开页面或点击“隐藏”也会清除显示。

十五分钟按最后一次后台操作计算，鼠标、键盘、点击和滚动等前台活动会续期；定时查询、后台轮询和仅切回页面不会续期。活动最多每分钟一次合并上报，服务器按原活动时间计算期限，不能恢复已经过期的授权。不同登录会话不共享授权。仅有工作区 owner/admin 角色不能进入平台后台。

验证器按平台管理员账号绑定一次。之后退出再登录、换浏览器或授权过期时，只重新输入验证码。Google、飞书和密码的日常登录流程不强制绑定这套后台验证器，普通业务账号不增加 2FA 门槛。本地与线上数据库独立时，绑定状态也各自保存。

进入后台后，在侧边栏“后台两步验证”查看自己的绑定状态或更换验证器。更换期间原验证器继续有效；输入新验证器的验证码确认后才完成替换，并生成新恢复码、撤销其他登录会话的后台授权。取消更换不会关闭现有验证器。

## 验证器丢失

可以使用一个尚未使用的恢复码验证。每个恢复码只可使用一次。验证器丢失后由维护人员核实身份，再使用受控的服务器重置工具；重置同时撤销该用户的全部登录会话和后台授权，随后重新登录、绑定。

不提供“只输入密码就关闭两步验证”的网页入口。连续五次错误尝试发生在五分钟内时，临时锁定十五分钟；计数存于数据库，跨进程生效。

## 安全边界

该方案降低数据库、备份或普通查询接口泄漏 IP 的风险，也降低仅获得登录密码就进入后台的风险。TLS 仍负责传输保护。应用必须先收到访问 IP 才能加密，因此这不是隐藏网络流量来源的方案。

部署时，写入端只需要公钥；提供解密接口的 API 进程需要私钥。若攻击者控制持有私钥的整个 API 进程，应用层 2FA 不能继续提供隔离保证。现有 IP 精确搜索保留带密钥的索引，该索引密钥也必须作为敏感密钥保护。

反向代理、CDN、云服务的访问日志及已经产生的历史备份不由本次应用字段改造自动清除，需要在上线检查中分别核对。
