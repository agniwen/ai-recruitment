# SSC responsibility pre-entry implementation plan

Goal: Add an administrator-maintained “SSC 负责组织” page, matching the existing pre-registration UI and the six columns of 公司对应的SSC人员.xlsx.

Architecture: Store independent workspace-scoped pre-entry relationships, without requiring registered users or existing organization records. A row records demandOwner (需求对接负责人), centerName (中心/部门), sscName (SSC 花名), telegram (SSC TG), email (SSC 邮箱), notes (备注). centerName, sscName, email are required; other strings may be empty. Trim all strings and normalize email to lower case. One email can have several centers; one center can have several SSCs. Reject duplicate workspace + trimmed/case-insensitive center + email with 409, including concurrent saves. No workbook import, member provisioning, permission grants, verified TG binding or notification-routing changes.

Global constraints: Reuse the existing feature worktree; preserve existing Offer and TG behavior. Owner/admin only, with new page permission and sidebar path registration matching pre-registration. Show search, pagination, sorting, empty/error states, create/edit dialog, delete confirmation. Six Excel fields must be visible. Additive migration only; no real candidate changes.

Task 1 — backend (agent offer_flow_review): Add independent Drizzle table + additive migration, schema/DAO/Hono CRUD mounted at /api/w/:slug/studio/ssc-responsibilities. GET query page/pageSize/search/sortBy(centerName|sscName|email|createdAt)/sortOrder; result {page,pageSize,records,total,totalPages}. Record includes id and createdAt/updatedAt ISO plus six string fields. POST/PATCH accept six string fields; POST201/PATCH200 returns {id}; DELETE returns {success:true}; missing records404, duplicate409. All access checks enforce real workspace owner/admin. Tests cover validation, pagination/search literal special chars, cross-workspace isolation, duplicate saves, update/delete/not-found and non-admin denial. Write tests first; root runs them using server cached dependencies.

Task 2 — UI (agent offer_ssc_ui): Add thin TanStack route /w/$slug/studio/ssc-responsibilities, feature grid/editor and loader following pre-registration. Register page action sscResponsibilities, label SSC 负责组织, sidebar adminOnly alongside pre-registration/ODC, page-path authorization and page explanation. Consume exact API/model of Task1. UI makes required fields clear; optional blank fields supported; notify save errors; refresh after successful changes. Allow entries without an existing member or center. Show concise text that this is pre-entry relationship maintenance. Tests exercise editor fields and correct CRUD/search behavior rather than CSS structure. Do not add import or auto populate spreadsheet rows.

Task 3 — integration (root): Run formatter/lint/typecheck and relevant backend/web/shared regression suites on isolated server test database. Review diff independently, resolve findings. Back up active data, deploy additive migration and exact tested source, verify API CRUD and workspace authorization with temporary records, visually inspect new page and preserve all existing Offer/member/role data. Leave browser at delivered page.

Review focus: Duplicates after case/space normalization; unregistered SSC saves; text organization names unknown to current catalogs; server-enforced admin and workspace boundaries; literal percent/underscore search.
